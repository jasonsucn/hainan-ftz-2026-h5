## 一、这是什么

一支单页 H5：用「一条线」串起海南自贸港封关第一年的制度、流量、产业与人。

它不是政策汇编，也不是旅游宣传片。视觉母题来自海南的**海岸线、黎锦纤维、港口灯轨与一道门**；全部内容只围绕一个问题：

> **封关，不是把岛围起来。是把海关的边界，变成经济的接口。**

- 2025.12.18，海南启动全岛封关运作；2026 年是第一年。
- 一线放开、二线管住、岛内自由。
- 零关税税目 21% → 74%；2026 年前三季度货物贸易 2,854.4 亿元，同比 +49.8%。
- 86 国免签；封关以来至 2026 年 9 月，离岛免税 275.4 亿元。
- 数据全部来自官方发布或官方媒体，逐条口径见 `docs/fact-check.md`。

**页面性质**：纪念性叙事 / 非官方发布；不构成政策解读或投资建议。

## 二、七幕

| 幕 | 标题 | 它做什么 |
|---|---|---|
| 00 | 过关 | 巨型「过关」+ 一条横穿画面的珊瑚线；先给压强，再给主张 |

## 三、视觉系统

- **底色**：深海墨绿黑 `#061311`；暖房（岛）`#140B08`；纸面 `#F1EADB`。
- **强调**：珊瑚红 `#E4552F`；姜黄 `#D6A23F`；玉灰 `#8FB6A4`。
- **字体**：Noto Serif SC（标题/数字）、Noto Sans SC（正文）、等宽小标签。优先本机已装字体，回退到 Songti / SimSun。
- **版式**：非对称编辑栅格；大字极端对比；全部卡片被拆成细线、编号、留白。
- **禁忌**：蓝紫渐变、毛玻璃、圆角卡片墙、通用粒子连线、全站 fade-in-up、数字 count-up。

**图像**：4 张原创 AI 底图（湿黑玄武岩 / 黎锦微距 / 深夜港口 / 刀锋石门），由 image-producer 用 gpt-image-2 生成；仅作氛围/材质，不作为新闻纪实。
**音乐**：89.9 秒无 vocals 氛围音轨，由 sound-producer 用 Suno 生成并做过 5 秒等功率循环接缝；默认静音，点击右上角 SOUND 后淡入。

## 六、质量与已知限制

- 桌面 1280×800、移动 390×844 均做了实机截图检查；移动端用 390×844 iframe 实测。
- Canvas DPR 上限 1.85；线 720 点、门 72 粒尘、潮 3 层波；目标 60fps，中端机自动降级。
- 支持 `prefers-reduced-motion`；无 WebGL 依赖；无第三方库/CDN。
- 声音默认静音，需要用户手势；本地文件播放不需要网络。
- 字体优先使用本机 Noto Serif SC / Noto Sans SC；没有字体文件的设备会回退到宋体/系统黑体，字形气质会有差异（未内嵌中文字体子集，以控制体积）。
- AI 图像为氛围/材质，不是新闻现场；页面已标注「纪念性叙事，不构成官方发布」。
- 关封为纪念设计，不是官方文件；编号由本机时间生成。
