# 《过关》独立视觉与体验评审

评审环境：桌面 1280×800；移动端 390×844（tools/mobile-test.html iframe）。只评审，不改页面。

## ① 三秒印象

黑场、米白宋体、一条贯穿屏幕的红线，把「过关」的「关」一半做成线描——气质像一支奢侈品广告片；但 8px 的装饰小字和几乎看不见的右侧目录，立刻把观感拉回「作品集模板」。

## ② 最像模板 / 最弱的 5 处

1. **01 线｜岛轮廓**：用一圈重度模糊的橙色 glow 勾海南，边缘发虚，像 PPT 外发光；右侧三行 A/B/C 规则加小数字，是最标准的「概念解释页」排法。
2. **03 岛｜行业手风琴**：展开瞬间整块铺品牌橙，与全站深色 + 米白体系硬断裂，是全页最明显的「网页组件」时刻。
3. **04 人｜米色整屏 + 黑色 ARRIVALS 表**：黑底数据表、VISA-FREE 小标签、城市 / 代码 / 状态三列，像把后台 dashboard 搬进叙事页。
4. **05 门｜数据条**：86 / 220 / 77 / 25 被压成一行 20px 数字 + 7px 标签，视觉权重还不如一句标语；`05 / THE GATE` 标签又改成居中，破坏 01–04 的左对齐节奏。
5. **06 海｜收尾页脚**：HAINAN 2026 字标 + 两列 7px 章节清单 + SOURCES 小字，像杂志版权页 / 站点 sitemap；本该是「关封」高潮，却最平。

## ③ 桌面端 3 个硬伤

1. **固定页头与右侧章节导航在浅色两幕（04 人 / 06 海）不反色**：米白底上的目录几乎不可见；滚动时大标题直接穿到 logo 和面包屑下面，页头没有遮罩。
2. **固定 HUD 与正文压字**：潮 0.85 的数据注释压住页头 logo，`23.8 万户 / +34.1%`、`22 家 / 139 家` 与右侧章节导航重叠；海 0.15 的 `DATA / 2026.10 FIRST YEAR` 压住 SOURCES 链接，尾句「封关以来……」又压住 `SCROLL TO PASS`。
3. **INDEX 面板在 1280×800 下把 06 海挤出折叠线**：面板没有滚动提示，关闭只剩右上角一个 ×，主入口实际漏掉最后一章。

## ④ 移动端 3 个硬伤

1. **01 线 0.9：门环右侧被 390 宽裁掉**，不是完整圆；`DRAG TO OPEN` 手柄落在屏底（距环心约 400px），拖动目标与视觉主体脱节，提示文字只有 10px。
2. **04 人：量化层级失衡**——三个同权指标里 86 被做成约 110px 橙色大字，134.4 / 275.4 只有 26px；页头无底色，白框 logo 直接压在大标题「门」上。
3. **全站移动字号失守**：正文 10–12px，注释与标签 7–8px（`VISA-FREE ENTRY / 截至 2026.05`、「个一线口岸」、05 门四个统计标签）在 390 宽上不可读；首屏「过关」与底部标语之间还空出约 175px，下半屏没有可操作内容。

## ⑤ 3 个可执行的提升动作

1. 把「固定页头 + 右侧章节导航 + 底部 HUD」换成随幕反色的两套主题（深色幕用米白、浅色幕用墨黑），并在 04 / 06 两幕加 32px 渐变蒙层——先消灭「看不见的导航」和所有压字。
2. 把 04 人的米色整屏 + 黑色 ARRIVALS 表换成与全站同底的深色细线列表（城市 / 代码 / 免签三列），86、134.4、275.4 统一到同一字号层级（如 64px 三连），让「人」这一幕是数据诗而不是 dashboard。
3. 把 01 线的发光模糊岛换成 1.5px 实线描边 + 沿线绘制动画；移动端把门环缩到 340px，把 `DRAG TO OPEN` 手柄贴到环的 3 点钟缺口，并把移动端字号下限提到 12px（注释 10px）。

## ⑥ 一句话结论

没有达到「顶级 H5 标杆」：概念、首屏和「一条线」的视觉母题够格，但全站只有一套「大标题 + 小字注 + 数字」版式，浅色两幕与数据呈现明显掉档，加上固定导航压字、移动端裁切这些硬伤，完成度停在「高级提案」，还差一套贯穿到页脚的反色 HUD 规范、04 / 06 两幕的重做，以及移动端字号与裁切返工。
